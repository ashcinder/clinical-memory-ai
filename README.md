# 临记 · Go + MySQL + Android Java

医生协作诊疗笔记与材料库：保存治疗过程，用文字、图片和音频检索历史经验，查看原始步骤与资料来源，接入可配置的 AI 模型进行检索辅助、经验回顾或日常对话。

## 技术文档与学习

完整说明见 [项目技术文档](项目技术文档.md)：覆盖实际架构、11 张数据库表、32 个 API 路由、文字/图片/音频检索、AI 接入、跨端同步、Web 与 Java Android 实现、本地启动、腾讯云部署、备份恢复和测试边界，并提供源码阅读路线与动手练习。文档依据 2026-10-28 当前工作区整理，不含真实凭据。

当前为公网分支 `codex/public-multiselect`，Web 入口为 https://124.221.183.247/clinical-memory/，Android 2.16.1 首次连接预填同一公网 HTTPS 地址。原内网分支 `codex/intranet-deployment` 保留独立代码与配置。

同一后端服务内，所有已登录账户都可查看、检索、编辑和删除笔记，以及已关联笔记的图片、录音和其他材料。资料类型与标签统一管理，一端修改后其他账户和设备通过同步版本刷新；并发编辑仍检查笔记版本，避免覆盖未读取的修改。

未登录访客无权读取资料。未关联笔记的临时上传仅上传账户可见；聊天记录、个人资料和模型密钥仍按账户保存。首次升级自动合并原有分类配置，保留原始笔记、附件及创建者记录，不复制或删除原有笔记。公网、本机和内网的不同数据库仍各自独立。

## 当前技术栈与四个目录

| 目录 | 内容 |
| --- | --- |
| `后端/` | Go 1.24+，标准库 HTTP 服务，MySQL 驱动，鉴权、检索、多模型对话 / 视觉 / ASR 适配与测试 |
| `前端APP/` | Android Studio 原生 **Java** 工程；Gradle 使用 Groovy，不含 `.kt` / `.kts` 源文件 |
| `前端Web/` | 浏览器原生 HTML、CSS、JavaScript；不需要 Node/npm 或打包工具 |
| `数据库数据/` | MySQL 建库与建表 SQL、SQL 备份、上传原件、旧版 SQLite 的只读归档 |

MySQL 的 InnoDB 引擎文件由你已经安装的 MySQL 服务管理，本项目不修改其 datadir，也不把运行中的 MySQL 文件移入工程。方便查看和测试的数据采用 SQL 导出与原始附件形式保存在“数据库数据”目录。

## 启动顺序

依次启动 **MySQL → Go 后端 → Web（可选独立进程）→ Android APP**。Web 和 Android 使用同一个后端账户和同一个 MySQL 数据库。

### 1. MySQL：确认服务、初始化项目数据库

你本机安装的 MySQL 命令位于 `/usr/local/mysql/bin/`。如果服务已经运行，不需要重新启动。先验证实际可用的 MySQL 管理员账户：

```bash
/usr/local/mysql/bin/mysql -u root -p
```

在密码提示处输入密码，终端不回显。若出现 `Access denied ... (1045)`，需要核对用户名、密码和端口；应用不会重置 root 密码。登录 MySQL 的账户密码与临记软件的登录账户密码是两套不同的凭据。

如果服务尚未运行，Oracle 安装包版 macOS 通常可通过系统设置的 MySQL 面板启动，或：

```bash
sudo /usr/local/mysql/support-files/mysql.server start
```

以下命令中的相对路径均从项目根目录开始。

首次准备项目：

```bash
cd 后端
# 若 .env 尚不存在，再复制；不要覆盖你已经填写的配置
[ -f .env ] || cp .env.example .env
bash setup-db.sh
```

`setup-db.sh` 会提示输入 MySQL 管理员密码，创建 `linji` 数据库与一个独立的应用账户，将**应用账户**写入 `.env`，文件权限为 0600；不保存管理员密码。使用其他管理员账户可执行 `bash setup-db.sh -admin-user=你的管理员用户名`。需要该管理员拥有建库、建用户和授权权限。此脚本只需首次运行，日常启动无需重复运行。

如果你已自行准备好数据库和应用账户，直接编辑 `后端/.env`，不必执行 setup-db.sh：

```dotenv
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=linji
DB_USER=你的MySQL应用用户名
DB_PASSWORD='你的MySQL应用密码'
HOST=127.0.0.1
PORT=8000
```

建库 SQL 在 `数据库数据/初始化.sql`，建表 SQL 在 `数据库数据/schema.sql`。后端首次启动会自动建表，应用账户需拥有该库的 SELECT、INSERT、UPDATE、DELETE、CREATE、INDEX、ALTER、REFERENCES 权限。密码包含 `#`、空格或 `$` 等符号时建议使用单引号包裹，避免变量展开；`!` 是英文和中文时属于不同字符。

### 2. Go 后端

终端一：

```bash
cd 后端
bash run.sh
```

等价命令为 `go run ./cmd/server`，首次会下载 go.mod / go.sum 固定的依赖。无需 Python、虚拟环境或 uvicorn。

- API：**http://127.0.0.1:8000/api/health**
- API 说明：**http://127.0.0.1:8000/docs**
- 后端自带 Web 页面：**http://127.0.0.1:8000**

默认监听本机。真机通过局域网访问时：

```bash
HOST=0.0.0.0 bash run.sh
```

仅改后端监听地址即可，不需要把 MySQL 3306 端口开放给手机。

编译为可执行文件：

```bash
go build -o bin/linji-server ./cmd/server
./bin/linji-server
```

启动时会检查数据库连接。若连接信息有误会直接给出说明并退出，不会偷偷退回 SQLite。

### 3. Web 前端

方式 A：后端已自带静态页面，直接访问 **http://127.0.0.1:8000**，不需要再启动前端进程。

方式 B：需要分别启动时，保留终端一，另开终端二：

```bash
cd 前端Web
bash run.sh
```

访问 **http://127.0.0.1:5173**。该进程使用 Go 提供静态页面，并把 `/api` 代理到后端，保持 Cookie 同源登录。后端未启动时会明确提示无法连接。不要用 `file://` 直接打开 index.html，也不要只用不带代理的静态服务器。

独立 Web 默认仅监听 `127.0.0.1:5173`，需要改端口可在 `.env` 设置 `WEB_PORT`。浏览器首次打开后创建**临记软件账户**，可选择导入明确标注的虚构示例。

### 4. Android Java APP

1. Android Studio 选择 **Open**，打开 `前端APP` 文件夹。
2. 等待 Gradle 同步。使用 Android Studio 自带 JDK 21（最低 JDK 17），并安装 Android SDK 33。
3. 选择模拟器或通过 USB 连接手机，点击绿色 **Run ▶**。
4. 在 APP 连接页填写后端地址，点击“连接 / 检查服务”，再用与 Web 相同的临记软件账户登录。

地址：

- Android Studio 模拟器：`http://10.0.2.2:8000`
- 真机：`http://电脑的局域网IP:8000`；电脑、手机同一 Wi-Fi，后端用 `HOST=0.0.0.0 bash run.sh`，并允许防火墙 8000 端口。
- 正式部署：使用 HTTPS 域名。Debug 允许本地 HTTP，Release 禁用明文 HTTP。

命令行构建：

```bash
cd 前端APP
./gradlew assembleDebug
# 已连接设备时安装（也可直接用 Android Studio Run）
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

APK：`前端APP/app/build/outputs/apk/debug/app-debug.apk`。业务源码全部为 Java；界面、文件选择、录音、鉴权和 HTTP 调用均为原生 Android 实现。targetSdk 33 用于本地测试，发布到应用商店前应升级 targetSdk 并配置正式签名。

## 现成测试资料

项目提供三组明确标注的虚构示例；创建软件账户后，在后端目录运行 `go run ./cmd/import-samples` 即可导入，每组包括文字、合成录音和公开授权的解剖示意图。Web 经验检索中的“试用示例”和 Android 首页的“试用图片 / 录音示例”可以直接选择测试素材，无需先把文件传到手机。也可在“数据库数据/测试资料”中自行选择原文件。详细来源和每组测试关键词见 `数据库数据/测试资料/使用说明.md`。

当前未配置视觉模型和 ASR 时，只有这六个字节完全相同的固定演示文件会匹配预置描述或转写；页面明确标注“示例预置文本”。真实新图、新录音需要配置识别服务或手动补充文本，不会被当作已自动识别。

## 配置 AI 模型、图片和音频

登录 Web 的“服务设置”或 Android 的“设置”，即可选择对话模型和图片模型，配置 DeepSeek、GLM、Kimi、MiniMax 的 API 密钥及模型名；也可以配置兼容 `/audio/transcriptions` 的音频转写服务地址、模型和密钥。保存后立即生效，无需重启。各平台账号需要拥有相应模型的 API 权限与额度。

1. 选择“对话与检索”和“图片理解”使用的服务；两项可以不同，也可以关闭。
2. 填写对应服务的 API 密钥，并检查对话模型和图片模型名称。可选配置音频转写服务。
3. 点击“保存模型设置”。已保存的密钥不会显示；留空会保留原密钥，勾选“清除”可以删除。

默认模型名称可按平台当前型号修改。各模型通过兼容 `/chat/completions` 的接口调用；图片模型需支持图片输入。可参考 [DeepSeek API](https://api-docs.deepseek.com/api/create-chat-completion/)、[智谱 GLM-4.6V](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-4.6v)、[MiniMax OpenAI SDK](https://platform.minimax.cn/docs/api-reference/text-openai-api) 和 [Kimi API 配置](https://www.kimi.com/help/kimi-api/api-troubleshooting)。音频服务地址应为 HTTPS 基础地址，例如 `https://服务地址/v1`（本机测试可用 localhost HTTP）。

模型设置按软件账户分开保存在 `数据库数据/ai-settings/`，文件权限为 0600，密钥不会返回给前端；它们**未进行静态加密**，请保护后端机器及数据目录。该目录已加入 Git 忽略，也不包含在普通备份中；恢复备份后需要重新输入 API 密钥。通过局域网 HTTP 配置时网络传输不加密，跨设备使用应配置 HTTPS。旧 `.env` 的 AI 设置在尚未通过界面保存配置时仍可作为所有账户的共享默认值；界面设置保存后该账户使用自己的配置。服务地址由管理员通过 `*_BASE_URL` 配置，保存账户模型设置或切换搜索开关后仍保留配置的兼容网关地址。数据库连接仍使用 `.env`。

对话或关键词整理将问题和已识别的查询内容发送给对话服务；图片上传/重新提取会将图片发送给视觉服务；经验回顾还会发送命中笔记的片段。调用可能产生费用，真实患者资料应先脱敏并确认所选平台的数据处理方式。

可选本地 PDF 提取工具来自 Poppler，如已使用 Homebrew 可安装 `brew install poppler`；不是 Go 服务的运行前提。所有提取结果都应人工核对。云端失败保留原件并提示重试；不把失败伪装成已识别。

Web 录音需 localhost / HTTPS 与麦克风权限。局域网 HTTP 下可上传已有音频；Android 原生录音不受这一浏览器限制。单个文件限 20MB。

## Web 与 Android 同步

两端连接同一个 Go 后端并登录同一个软件账户，即共用笔记、材料、对话、个人信息和模型配置。模拟器的 `10.0.2.2` 对应电脑的 `127.0.0.1`；真机需使用电脑局域网地址。

- 笔记统一为 UTF-8 纯文本正文、标签数组、按顺序保存的步骤数组、分类、记录日期和附件 ID；多行正文和步骤顺序保持一致。
- 两端在前台空闲时约每 5 秒检查更新，也可点击 Web 顶栏“同步”或 APP 顶部账户状态手动刷新。切回窗口时会检查更新。
- 编辑笔记、输入查询或修改配置时暂缓自动刷新，避免覆盖未保存内容；旧版本的笔记或模型配置保存时会返回冲突提示。
- 显示名称可在设置页编辑，用户名保持不变；账户信息保存在 MySQL。模型配置由同一后端按账户保存，两端不用重复填写密钥。
- 这不是离线同步；两端需能访问同一后端。已有检索结果在资料更新后需重新发起检索，不会自动产生新的 AI 调用。

## 检索和数据保存

Go 将笔记、标签、步骤和附件文本分成中文单字/双字及英文词，持久写入 MySQL 的 `note_terms` 倒排索引，按匹配权重排序。无需修改 MySQL 的 ngram 配置或添加向量数据库。修改正文/材料文本、关联/解除关联及删除时通过事务同步更新索引。

配置对话服务后，模型先从查询中整理关键词和同义词，MySQL 召回候选，再由模型筛掉仅因通用词命中的无关条目（候选最多 40 篇）；历史经验对话最多取 5 篇共享资料库的笔记供模型总结，页面显示可打开的来源。图片在上传时先由视觉模型生成可核对的描述，既有图片可在材料页面选择“重新提取”，关联笔记的索引会更新。结果是基于识别文本和关键词的检索，并非图像向量相似度匹配；模型可能误识别或遗漏穴位，结果必须核对原图与笔记。AI 关键词整理失败时回退到原文检索并提示。日常对话不自动读取资料库，主动附加的材料除外。

删除笔记会保留原始材料；删除材料会移除文件与识别文本。旧对话仍保存当时的来源摘要，删除笔记不会改写历史回复。

### 备份

先停后端，避免备份过程中上传/删除原件；MySQL 可以继续运行：

```bash
cd 后端
bash backup.sh
# 或指定路径
bash backup.sh -output '/你选择的目录/临记备份.tar.gz'
```

默认输出到 `数据库数据/backups/`，包含 `linji.sql` 和 `uploads/`，不包含 `.env`、模型配置文件或密钥。使用本机 mysqldump，连接密码通过权限为 0600 的临时配置传入，不放在命令行参数中。找不到命令时设置 `MYSQLDUMP_BIN=/usr/local/mysql/bin/mysqldump`。

恢复时先备份现有资料并停后端，将 `linji.sql` 导入**专用空数据库**，再恢复 `uploads/`，调整 `.env` 指向恢复库。SQL 中含账户/会话及隐私资料，请妥善保管。页面“导出笔记 JSON”是便于查看的导出，不是含附件原件的完整备份。

## 本地检索与云端开关

Web 和 Android 的检索页、历史经验对话及服务设置都有“云端 AI 搜索”开关，同一账户在设备间同步。关闭后，**新上传材料的识别、经验检索与历史回顾不调用云端 AI**，已保存的 API 密钥仍保留；“日常对话”是独立的主动云端功能。

- 图片：SHA-256 精确匹配 + pHash / dHash 与颜色校验，匹配相同或近似图片并返回其关联笔记。首次查询会给旧图片补建指纹，缓存在 MySQL 的 image_fingerprints 表；删除材料时级联删除。指纹适合原图、缩放与压缩版本，不识别不同角度照片的穴位语义。
- 图片文字：macOS 使用系统 Vision；其他系统使用 Tesseract 中英文语言包。提取文字后进入原有文字索引。
- 音频文字：本地 whisper.cpp（Whisper base 多语言模型）+ FFmpeg，支持 **120 秒以内**的录音。转写可能有错字，点击材料可核对和修正；已保存的转写文字也能直接搜索。超过时长会提示分段，不会默默截断。

这台 Mac 已准备好本地识别组件。迁移到其他电脑时，在联网环境中执行一次：

```bash
bash 后端/setup-local-search.sh
```

首次下载引擎与模型，完成后识别无需联网。模型在 `数据库数据/models/`，已忽略 Git；MySQL 和原始材料仍保留在原位置。Linux 需安装 tesseract、whisper-cli、ffmpeg、ffprobe，再执行脚本下载语言包与模型。可选 `LOCAL_ASR_MODEL`、`OCR_DATA_DIR` 用于自定义本机模型位置；模型服务 API 仍在前端设置。

关闭开关后，已有云端识别文字会继续作为已保存数据参与本地搜索；开关不会删除或自动重写已有材料。对旧的未识别材料可点击“重新提取”。

## 图片粘贴与结果阅读

在 Web 的经验检索框、AI 对话框或笔记编辑框中，复制截图或图片后按 **⌘V / Ctrl+V** 即可添加图片。支持 PNG、JPG、WebP，单文件不超过 20MB；一次检索或对话最多关联 5 份材料。复制图片网址会按文字处理，需要复制图片本身。上传后可预览、查看识别状态或移除；图片识别依赖设置中配置的图片服务，未识别时可点击材料补充文本。仅粘贴图片也可以发送对话。

Web 与 Android 的检索结果展示匹配关键词、匹配位置、原文片段、已记录步骤和原始材料。图片使用鉴权缩略图，可点击查看原件；音频与文档可打开核对。步骤较多时先显示前三项，打开完整记录查看全部。分类数量只统计本次结果；语义相关但没有直接文字匹配时会提示核对原文。

升级后重启 Go 后端，Web 强制刷新，Android 安装新版 APK。缩略图和匹配信息由新版后端提供。

```bash
cd 后端

```

没有测试 MySQL 连接时，数据库集成测试会明确跳过。使用**专用测试实例**运行完整测试：

```bash
MYSQL_TEST_DSN='root@tcp(127.0.0.1:3307)/?charset=utf8mb4&parseTime=true' go test -race ./... -count=1
```

示例中的 3307 是本次独立验证实例，不是你的日常 MySQL 端口；不要照抄为日常 `.env`。测试只创建/删除随机 `linji_test_` 前缀的库，测试账户需要相应建库和删库权限，不会清空已有业务数据库。详细结果见 `后端/验证记录.md`。

## 旧版本与使用边界

当前版本使用 Go 和 MySQL，不包含历史数据库或旧版归档。

这是个人本地测试原型，已实现密码哈希、过期会话、登录限流、资源归属校验、上传大小限制、Web HttpOnly Cookie 和 Android Keystore 令牌加密。未提供医院级审计、角色权限、静态数据加密与灾备。启用云端服务会发送相关问题、命中笔记片段或材料到对应服务，应先脱敏并取得适当授权。模型回复与历史经验需要医生核对。

## 临床学习资料目录（2.5）

检索结果以已保存原文、对应条目和原始材料为中心。资料按用途分为诊疗记录、操作教程、知识要点、经验复盘、随访记录、图谱资料，另外保留自定义分类；标签可补充主题、部位和待复习/待带教确认等学习线索。旧“教程”“知识”“经验总结”“诊疗笔记”等名称会归入统一目录，原 category 和正文不被重写。

`GET /api/taxonomy` 返回统一目录、数量和学习标签提示；笔记响应的 `note_type` 是派生类型。列表和检索可传 `note_type` 与 `tag`，在数据库 LIMIT 前过滤。检索 `search_match.passages` 返回实际命中的正文、材料或步骤；短原文尽量完整显示，长原文定位命中段落，并可在结果页展开全文。它们是历史来源文本，不是 AI 自动生成的操作指令。
