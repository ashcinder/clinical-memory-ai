# 原生 Web 客户端

内网部署时直接打开统一 HTTPS 入口，例如 `https://linji.internal.example/clinical-memory/`（替换为实际域名）。Web 自动使用当前站点与子路径的 API，电脑无需运行本地后端或修改 app.js。与手机 App 连接同一后端并登录同一账户即可共用数据。内部 CA 需在电脑受信任，录音需 HTTPS。参阅 [内网部署说明](../后端/deploy/intranet/README.md)。

HTML、CSS、JavaScript，无 Node/npm 构建依赖。

启动方法：

1. 启动 MySQL 和 Go 后端。
2. 直接访问 http://127.0.0.1:8000；后端已托管 Web 文件。
3. 如需独立启动，运行本目录 `bash run.sh`，访问 http://127.0.0.1:5173。脚本调用 Go 的静态服务器，将 /api 同源代理到后端。

不要通过 file:// 打开 index.html，也不要用缺少 API 代理的静态服务器。通过 HttpOnly Cookie 登录，不在 localStorage 中存储令牌。动态正文按文本转义展示，AI 回复用纯文本和来源按钮呈现。

localhost / HTTPS 支持 MediaRecorder 录音，需授权麦克风，最长两分钟。单个材料限 20MB。

经验检索的“试用示例”提供固定图片和录音：仅当原始文件 SHA-256 一致时使用预置文本。新文件需要识别服务或手动补充文本。

2.4 界面改版：统一资料阅读层级，结果显示命中依据、原文、可展开步骤和鉴权原件；支持结果排序、材料筛选、图片粘贴、快捷检索、失败重试与草稿退出保护。手机端底部导航及可展开的历史对话入口适配小屏。

2.5 增加用途目录与学习标签，压缩检索后的输入区，优先显示真实命中原文。可在限定类型中检索，在结果中组合类型/标签筛选，并原地展开长文和长教程。资料页过滤在数据库分页前完成。

检索结果中的资料类型与标签可以组合使用。常用标签直接显示，“查找标签”可搜索完整目录；已选条件可以单独取消或一键清除。

AI 对话使用左侧历史列表与底部输入框；Enter 发送，Shift+Enter 换行。支持 Markdown 排版、复制回答、笔记来源、历史查找和粘贴图片。

对话输入框在空白页、发送、回复和历史会话中统一停靠底部；错误与上传状态不挤动输入框或发送按钮。

账户入口移到右上角，可打开个人账户或退出登录；设置入口固定在侧栏底部。顶部按钮可将侧栏收起为图标导航，“AI 对话”右侧箭头可单独折叠历史列表；折叠偏好保存在当前浏览器，保留草稿。

历史会话支持卡片删除按钮、右键菜单及 Shift+F10。删除前显示确认；取消或请求失败保留原会话，删除其他会话保留当前草稿。删除当前会话后回到新对话，聊天记录在服务端删除，笔记和材料不受影响。

在检索/资料页点击“管理分类与标签”，或在设置中打开“分类与标签”，可新增、重命名和删除；未使用的条目也保存到 MySQL，同一账户在 Web 与 APP 之间同步。编辑笔记时可选择已有标签。删除标签会从该账户的笔记中解除关联；删除资料类型会将其笔记归入“其他资料”，正文、步骤和附件保留。“其他资料”可改名，作为兜底类型保留。
