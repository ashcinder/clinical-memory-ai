- Processing: independently bake gender_male / gender_female morphs and skin transforms into static mesh positions; retain materials / texture maps / UVs; discard runtime morphs, skinning and rigs; recompute normals; normalize height to 2 model units.
- This is a realistic reference avatar, not a photogrammetry scan or clinically calibrated anatomical dataset.
