# 临记多模态测试资料

这三组均为**虚构演示资料**，不是患者记录、不包含真实患者照片或医疗建议。每组包含一篇文字、一张公开授权的解剖示意图、一段由 macOS 系统语音合成的中文录音，并对应一篇可导入的演示笔记。

| 主题 | 文字搜索示例 | 测试图片 | 测试录音 |
| --- | --- | --- | --- |
| 咳嗽随访 | 咳嗽、呼吸系统、复诊 | 图片/呼吸系统示意图.png | 录音/咳嗽随访与呼吸系统资料.wav |
| 呼吸训练 | 呼吸训练、肺部观察 | 图片/肺部示意图.png | 录音/呼吸训练与肺部观察.wav |
| 皮肤观察 | 瘙痒、皮疹、复诊 | 图片/皮肤结构示意图.png | 录音/皮肤瘙痒与皮疹观察.wav |

打开 Web 的“试用示例”或 APP 的“试用图片 / 录音示例”，选取素材后点击“检索经验”；也可以用文字检索这些词，或手动上传上列原始图片/录音。没有配置 AI 识别服务时，Web 与 APP 会对**完全相同的这六份原始演示文件**比对 SHA-256，使用标注为“演示文件预置描述/转写”的文本完成检索。更换、编辑、截图或重新录制的文件不会命中该匹配；真实的新图片和录音仍需设置视觉模型与 ASR 服务，或手动补充文本。

图片来源：

- 呼吸系统示意图：[NIH NHLBI / Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Human_respiratory_system-NIH.PNG)，美国政府作品，来源页标注美国公共领域。
- 肺部示意图：[LadyofHats，Tyrol5 裁剪 / Wikimedia Commons](https://commons.wikimedia.org/wiki/File:The_human_lungs.png)，作者发布至公共领域。
- 皮肤结构示意图：[NIH NIAID、Ryan Kissinger / Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Skin_Cross-Section_(NIH_BioArt_677).png)，来源页标注美国公共领域。

语音由 macOS `say` 的 Tingting 声音合成，不是医生或患者真实录音。文字为专门撰写的虚构测试材料。

在“后端”目录执行 `go run ./cmd/import-samples`，即可将演示笔记导入当前软件账号，不会替换已有记录；重复运行不会重复导入已存在的案例。
