# 真实 API 检索实测资料

这些文件用于检验真实接口调用，均不含患者资料。它们不在客户端固定示例哈希清单中。

- `hegu.png`、`zusanli.png`：自行绘制的合谷 LI4、足三里 ST36 文字标签卡片；不用于临床定位。
- `lungs-anatomy.png`：肺部解剖示意图，来自 [LadyofHats / Wikimedia Commons](https://commons.wikimedia.org/wiki/File:The_human_lungs.png)，作者发布至公共领域。与上级目录已有肺部示意图同源。
- `lungs-query.jpg`：同一肺部示意图缩放、重新编码的查询版本，文件内容与历史 PNG 不同。
- `hegu.wav`：macOS Tingting 合成的中文查询，不是患者或医生真实录音。
- `query.txt`：文字材料查询。

这些小样本验证接口与检索链路，不能据此估计无标签真实穴位照片的定位准确率。
